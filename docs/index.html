Doodlechain

The drawing telephone game for your group chat

Someone writes “a cat doing taxes”. The next person draws it. The next guesses the drawing. Everyone plays whenever they have a minute, then the whole chain is revealed.

  • One link in the chat, no app, no sign-up
  • Turns take a minute, on your phone
  • Same link for a new round every day

Start a game, free

How it works

  1. 1

    Send the link

    Create a game and drop the link in your WhatsApp, iMessage, Messenger or Discord group. Friends join with a nickname.

  2. 2

    Draw or guess

    Each turn you see only the step before yours. Several chains run at once, so nobody waits.

  3. 3

    Watch it fall apart

    When everyone has played, or at the time you chose, the reveal plays each chain from start to finish.
